# Oceanic-AI
An ocean waste detection system utilizing the YOLOv8 object detection model.

## Overview
This project leverages computer vision to identify and classify marine debris in bodies of water. The model was trained and evaluated using Google Colab, utilizing the Ultralytics YOLOv8 architecture for high-speed, accurate bounding box predictions on environmental image datasets.

## Technologies Used
- Python
- YOLOv8 (Ultralytics)
- Google Colab
- OpenCV# Oceanic-AI-YOLOv8
